GUIDA FIREBASE (versione 1.07) - piano gratuito "Spark", nessuna carta richiesta

1) CREA IL PROGETTO
   - Vai su https://console.firebase.google.com e accedi con un account Google.
   - "Aggiungi progetto" > dai un nome (es. torneo-san-michele) > Google Analytics non serve > Crea.

2) CREA IL DATABASE
   - Menu a sinistra: Build > Firestore Database > "Crea database".
   - Scegli una sede in Europa (es. eur3 o europe-west) > modalità "Produzione" > Crea.

3) ATTIVA L'ACCESSO ADMIN
   - Build > Authentication > "Inizia" > scheda "Metodo di accesso" > Email/password > Abilita (solo il primo interruttore) > Salva.

4) COLLEGA IL SITO
   - Ingranaggio in alto a sinistra > "Impostazioni progetto" > in basso "Le tue app" > icona Web "</>".
   - Dai un nome, NON spuntare Firebase Hosting > "Registra app".
   - Copia i valori di firebaseConfig (apiKey, authDomain, projectId, appId...) e incollali nel file
     firebase-config.js al posto di INCOLLA_QUI. Salva il file.

5) PROTEGGI I DATI (importante)
   - Firestore Database > scheda "Regole" > cancella tutto > incolla il contenuto del file firestore.rules > Pubblica.
   - Risultato: tutti possono LEGGERE, solo l'admin può SCRIVERE.

6) PUBBLICA SU GITHUB
   - Carica tutti i file della cartella (index.html, sw.js, manifest.json, version.json, firebase-config.js, icons/...).
   - Per ora il file data.json non serve più.

7) CREA SUBITO L'ADMIN
   - Apri il sito, tocca l'omino e crea nome utente e password. Fallo prima di dare l'indirizzo agli altri:
     il primo che crea l'account diventa l'unico admin e nessuno potrà più crearne altri.
   - Se avevi dati sul vecchio sistema: l'app propone di caricarli online (se sei sullo stesso dispositivo),
     oppure usa Gestione > Impostazioni > Importa file con il vecchio data.json.

8) COME FUNZIONA ORA
   - Ogni modifica dell'admin è salvata online e compare in tempo reale su tutti i dispositivi, senza caricare file su GitHub.
   - Su GitHub vanno caricati solo gli aggiornamenti dell'app (nuove versioni); i dati del torneo restano su Firebase.
   - Funziona anche con connessione debole: i dati già visti restano consultabili offline.

NOTE
   - I valori di firebase-config.js non sono segreti: la sicurezza è garantita dalle regole del punto 5.
   - Il piano gratuito (50.000 letture al giorno) è ampio per un torneo in casa.
   - Se perdi la password admin: in Firebase elimina l'utente (Authentication > Utenti) e il documento meta/admin
     (Firestore Database > Dati > meta > admin), poi ricrea l'admin dall'app. I dati del torneo restano.
   - Nome utente e password dell'admin non sono email vere: non esiste recupero automatico, annotali.
